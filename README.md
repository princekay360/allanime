# allanime

A fresh, mobile-first anime app foundation built with Expo + React Native.

## Prerequisites

- Node.js 20+
- npm 10+

## Getting started

```bash
npm install
npm run start
```

Then open the app in:
- Expo Go on iOS/Android (recommended mobile-first flow)
- Android emulator: `npm run android`
- iOS simulator (macOS only): `npm run ios`
- Web preview: `npm run web`

## Current scope

- Mobile-first home experience scaffold
- Continue watching section
- Trending anime chips
- Upcoming release list

This project is intentionally built from scratch and ready to evolve into a full Seanime-style experience.
